Shared replay links

Every share link created from this browser, newest first. A link is a bearer token: anyone it reaches can watch the replay, which includes your opponent's display name and the match chat. A share can't be unshared. There is no way to revoke one early — each expires on its own 7 days after it was created, when the endpoint deletes the encrypted copy, and that sweep can run up to a day late. Re-check asks the endpoint whether a share's copy is still there. Clearing an expired share removes this local record and nothing else; the record is the only place its decryption key is kept, so a cleared link can never be rebuilt.

Series detection

Detected series are worked out from your matches each time this page draws them and are never written to your records, so only the groupings you make by hand are stored. Matches recorded before the extension started reading the format fall back to a 45-minute gap between games, which is the one case the timing rule is still used for.

Your data

JSON carries matches, game logs and card codes and is what an import reads — it merges by match id, so importing the same file twice is safe. CSV is flattened for a spreadsheet and includes the analysis columns. Replays are in neither, and never come back from an import.

Archive & clear downloads everything first, then asks once more, then wipes matches, logs, card lists, share records and replays. Viewing an archive is read-only — your live data stays where it is and every control that changes something is disabled until you exit.

Clear everything

Deletes every match, log, card list, share record and replay in this browser, with no copy taken. If you might want the data later, use Archive & clear instead.

Where your data lives

Match records and settings are in this browser's extension storage; replays are in its own database. Nothing is uploaded anywhere, with one exception: a replay you explicitly choose to share, which is encrypted in this browser first. lists every share you have made.
