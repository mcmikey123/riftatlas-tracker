Shared replay links

Every share link created from this browser, newest first. A link is a bearer token: anyone it reaches can watch the replay, which includes your opponent's display name and the match chat. A share can't be unshared. There is no way to revoke one early — each expires on its own 7 days after it was created, when the endpoint deletes the encrypted copy, and that sweep can run up to a day late. Re-check asks the endpoint whether a share's copy is still there. Clearing an expired share removes this local record and nothing else; the record is the only place its decryption key is kept, so a cleared link can never be rebuilt.
